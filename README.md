# 🧠 НейроКоманда

Локальная мультиагентная система на Ollama: команда нейросетей выполняет твои задачи
на твоём ПК — **без облаков и без утечки данных наружу**.

## Команда

| Роль | Модель | Что делает |
|---|---|---|
| 🧠 Оркестратор | `qwen2.5:14b-instruct-q4_K_M` | принимает задачу, строит план, раздаёт шаги, пишет отчёт и XLS |
| 💻 Программист | `qwen2.5-coder:7b-instruct-q4_K_M` | пишет и выполняет Python-код, чинит ошибки |
| 🌐 Исследователь | `llama3.1:8b-instruct-q4_K_M` | интернет: поиск, вкладки, клики, формы, анализ страниц |
| 📁 Файловый | `gemma3:4b-it-q4_K_M` | файлы и папки внутри белой папки |
| ⚙️ Исполнитель | `llama3.2:3b-instruct-q4_K_M` | простые команды Windows, рутина |
| 🧬 Память | `nomic-embed-text` | RAG-векторы: воспоминания по смыслу |

Оркестратор живёт в RAM постоянно; воркеры подгружаются по требованию и выгружаются
после простоя (лимит — 2 воркера одновременно, настраивается `NEURO_MAX_WORKERS`).

## Безопасность

* Файлы — **только** белый список (по умолчанию `D:\Проекты`); системные пути в чёрном списке безусловно.
* Опасные действия (удаление, запись, скачивание, опасные команды/код) — **только после твоего подтверждения** в интерфейсе.
* Все модели локальные (Ollama), данные наружу не уходят.

## Установка (Windows)

1. Установи Python 3.10+ и Ollama, загрузи модели:
   ```powershell
   ollama pull qwen2.5:14b-instruct-q4_K_M
   ollama pull qwen2.5-coder:7b-instruct-q4_K_M
   ollama pull llama3.1:8b-instruct-q4_K_M
   ollama pull gemma3:4b-it-q4_K_M
   ollama pull llama3.2:3b-instruct-q4_K_M
   ollama pull nomic-embed-text
   ```
   (модели лучше держать на диске D: `setx OLLAMA_MODELS "D:\OllamaModels"`)
2. Скопируй эту папку на ПК (например, `D:\Проекты\neuroteam`).
3. Запусти **run.bat** — он создаст окружение, поставит зависимости и браузер Playwright,
   затем запустит сервер и откроет интерфейс `http://127.0.0.1:8000`.

## Использование

* Напиши задачу в поле внизу слева → Оркестратор покажет план → агенты работают.
* Справа — «Глаз браузера»: скриншоты видимого браузера агента + журнал действий.
* 🔒 Карточка подтверждения — разреши или запрети опасное действие.
* 📊 «Отчёт XLS» — рабочая таблица: Дата | Задача | Исполнитель | Статус | Результат | Время.
* Текстовые отчёты лежат в `app/data/reports/otchet_*.txt`.
* 🗑 «Очистить память» — стирает RAG-воспоминания.
* По завершении — уведомление браузера со звуком.

## Настройки (переменные окружения)

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `NEURO_WHITELIST` | `D:\Проекты` | белые папки через `;` |
| `NEURO_MAX_WORKERS` | `2` | сколько воркеров держать в RAM |
| `NEURO_HOST` / `NEURO_PORT` | `127.0.0.1` / `8000` | адрес сервера |
| `OLLAMA_URL` | `http://127.0.0.1:11434` | адрес Ollama |
| `NEURO_DEMO` | `0` | `1` — демо-режим интерфейса без Ollama |
| `MODEL_ORCH`, `MODEL_CODER`, `MODEL_RES`, `MODEL_FILES`, `MODEL_EXEC`, `MODEL_EMBED` | имена выше | замена моделей |

## Структура

```
app/
  main.py            сервер FastAPI + WebSocket
  config.py          настройки и ограничения
  ollama_client.py   чат/эмбеддинги/загрузка моделей
  agents/            промпты ролей и исполнитель задач (план → шаги → отчёт)
  tools/             файлы, оболочка+Python, видимый браузер Playwright
  memory/            RAG-память (SQLite + nomic-embed-text)
  reports/           XLS и текстовые отчёты
  security/          белый/чёрный списки, опасные операции, подтверждения
  static/            веб-интерфейс (русский)
```
