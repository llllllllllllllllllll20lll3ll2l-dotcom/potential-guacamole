# Game Memory Agent

ИИ-ассистент, который в реальном времени ищет и меняет значения в памяти **офлайн-игр** на Windows — по обычным текстовым командам на русском.

```
Вы> подключись к game.exe и найди 100 золота
ИИ>  ⚙ list_processes({})
     ← {"processes": [...]}
     ⚙ attach({"name": "game.exe"})
     ← {"pid": 1234, "name": "game.exe"}
     ⚙ scan({"dtype": "i32", "value": 100})
     ← {"count": 2, "addresses": ["0x1F2A9B40", "0x23C41D08"]}
     Нашёл 2 адреса. Потрать немного золота в игре и скажи новое значение.
Вы> теперь 87
ИИ>  ⚙ next_scan({"dtype": "i32", "value": 87})
     ← {"count": 1, "addresses": ["0x1F2A9B40"]}
     Остался один адрес 0x1F2A9B40. Записать туда 999999?
Вы> да
ИИ>  ⚙ write({"address": "0x1F2A9B40", "dtype": "i32", "value": 999999})
     ← {"address": "0x1F2A9B40", "value": 999999}
     Готово, золото изменено.
```

## Как это устроено

Три слоя, никаких внешних чит-движков:

| Слой | Что делает | Файлы |
|---|---|---|
| **Мозг** — LLM | Понимает русский запрос, решает, какой инструмент вызвать | `agent.py` |
| **Мост** — function calling | Описывает инструменты (scan, write, freeze...) в JSON-схемах | `tools.py` |
| **Руки** — доступ к памяти | ctypes → `OpenProcess`, `VirtualQueryEx`, `ReadProcessMemory`, `WriteProcessMemory` | `memory.py`, `core.py` |

LLM работает через OpenAI-совместимый API — подойдёт локальная **Ollama**, LM Studio, OpenRouter, DeepSeek или OpenAI.

## Установка (Windows 10/11 x64)

### 1. Python 3.11+ **обязательно 64-битный**
[python.org/downloads](https://www.python.org/downloads/windows/) → «Windows installer (64-bit)». При установке отметь **Add python.exe to PATH**.

Проверка:

```bat
python --version
python -c "import struct; print(struct.calcsize('P') * 8)"
```

Вторая команда должна вывести `64`. На 32-битном Python не будут видны адреса выше 4 ГБ — у современных игр почти вся память там.

### 2. Проект и зависимости

```bat
git clone <адрес-репозитория> game-memory-agent
cd game-memory-agent
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Зависимость одна — `openai` (доступ к памяти написан на чистом ctypes, без pymem и Cheat Engine).

### 3. Локальная модель (Ollama)

```bat
winget install Ollama.Ollama
ollama pull qwen2.5:7b-instruct
```

| Модель | Память | Когда брать |
|---|---|---|
| `qwen2.5:3b-instruct` | ~3 ГБ | слабая видеокарта / только CPU |
| `qwen2.5:7b-instruct` | ~6 ГБ | **рекомендуется**: русский + tool calling |
| `qwen2.5-coder:7b` | ~6 ГБ | если много работаешь с hex/AOB |
| `llama3.1:8b` | ~7 ГБ | альтернатива, русский чуть хуже |

Проверка, что сервер поднялся: <http://localhost:11434> → «Ollama is running».

### 4. Запуск **от имени администратора**

Терминал (PowerShell/CMD) → правый клик → «Запуск от имени администратора». Без этого `OpenProcess` для многих игр вернёт «Отказано в доступе».

```bat
python main.py
```

Есть готовые ярлыки: `start.bat` (чат с ИИ) и `start-cli.bat` (без ИИ).

## Использование

### Чат с ИИ

Просто пиши по-русски:

- «покажи запущенные процессы»
- «подключись к EldenRing.exe»
- «найди значение 250, тип float»
- «я потратил патроны, теперь 137»
- «заморозь здоровье на 100, чтобы не уменьшалось»
- «какой сейчас статус?»

ИИ сам вызывает `list_processes → attach → scan → next_scan → write` и показывает каждый шаг.

### CLI без LLM

```bat
python main.py --cli
```

```
mem> attach game.exe
mem> scan i32 100
mem> next i32 87
mem> write 0x1F2A9B40 i32 999999
mem> freeze 0x1F2A9B40 i32 999999
mem> unfreeze
```

Удобно, когда модель не справляется или нужно быстро.

## Как искать значение

1. **Скажи точное число с экрана.** Целое (золото, патроны) — `i32`. Дробное (HP 75.5) — `f32` или `f64`. Если не находится — перебери `u32`, `i64`, `f64`: игры хранят одно и то же по-разному.
2. **Измени значение в игре** (потрать/получи) и назови новое — `next_scan`.
3. Повторяй, пока не останется 1–5 адресов.
4. Запиши новое значение (`write`) или включи заморозку (`freeze`).

**Заморозка** (`freeze`) — фоновый поток каждые 100 мс перезаписывает значение, игра не может его изменить. Снимается `unfreeze`.

**AOB-скан** — поиск по сигнатуре байтов с wildcard: `48 8B ?? 90`. Нужен, когда значение меняется вместе с перезапуском игры, а сигнатура кода — нет. Полноценные pointer chain (статические адреса) проще делать в Cheat Engine.

## Важные ограничения

- **Адреса меняются при каждом запуске игры** (ASLR). После перезапуска — подключайся и сканируй заново. Для постоянных читов нужны pointer chains / AOB-инъекции.
- **Первое сканирование медленное**: 1–3 ГБ памяти читается чанками по 4 МБ, это 10–60 секунд. Дальше `next_scan` мгновенный.
- **Только точные значения.** «Неизвестное начальное значение» (как в CE) не поддерживается — сначала нужно число с экрана.
- **Только офлайн-игры.** Онлайн-игры с античитом (EAC, BattlEye, Vanguard, Ricochet) = бан аккаунта. Не делай так.
- **Антивирус** может отреагировать на чтение чужой памяти — это ложное срабатывание; добавь папку в исключения, если мешает.
- **Приватность**: облачная модель видит названия игр и значения. Если критично — используй локальную Ollama.

## Конфигурация

Переменные окружения. В PowerShell: `$env:GMA_MODEL='qwen2.5:7b-instruct'`, в CMD: `set GMA_MODEL=...`

| Переменная | По умолчанию | Что значит |
|---|---|---|
| `GMA_BASE_URL` | `http://localhost:11434/v1` | OpenAI-совместимый endpoint |
| `GMA_API_KEY` | `ollama` | ключ (для Ollama любой) |
| `GMA_MODEL` | `qwen2.5:7b-instruct` | имя модели |

Примеры:

```bat
:: LM Studio (включить Local Server на порту 1234)
set GMA_BASE_URL=http://localhost:1234/v1
set GMA_API_KEY=lm-studio
set GMA_MODEL=qwen2.5-7b-instruct

:: OpenRouter
set GMA_BASE_URL=https://openrouter.ai/api/v1
set GMA_API_KEY=sk-or-...
set GMA_MODEL=qwen/qwen-2.5-7b-instruct
```

## Если что-то не работает

| Симптом | Причина / решение |
|---|---|
| `OpenProcess ... код 5` | Терминал не от администратора |
| «Процесс не найден» | Игра не запущена или имя без `.exe`; посмотри `list_processes` |
| Адреса > 0x7FFFFFFF не находятся | 32-битный Python — поставь x64 |
| `connection refused` от Ollama | Сервер не запущен: `ollama serve` или приложение Ollama |
| Модель не вызывает инструменты | Модель слабая — возьми `qwen2.5:7b-instruct` или-cloud |
| Запись не применяется | Игра перезаписывает значение — используй `freeze` |
| После перезапуска игры адрес битый | Норма (ASLR) — переподключись и сделай новый scan |
